OUR MOMENTS — はじめかた（アート背景版）
========================

【まず試す】
1. ZIPを展開します。
2. index.html と同じ場所に assets フォルダがあることを確認します（背景イラストに必要です）。
3. index.html を開きます。
4. 初期PIN「1108」を入力して、扉を開きます。
5. 星の図書館で写真・思い出・手紙を追加してみてください。

注意：index.htmlを直接開く方法はデモ確認用です。ホーム画面に追加するPWAとして使うには、HTTPSで公開する必要があります。

【無料でPWAとして公開する：GitHub Pages】
1. GitHubにログインし、新しいリポジトリを作成します（例：our-moments）。
2. このフォルダの中身（index.html、manifest.json、sw.js、iconsフォルダ、assetsフォルダ、supabase_setup.sql、はじめかた.txt）を、リポジトリの一番上にアップロードします。
3. リポジトリの Settings → Pages を開きます。
4. Build and deployment で「Deploy from a branch」を選び、Branch「main」、Folder「/ (root)」を選び Save。
5. 表示された https://<ユーザー名>.github.io/<リポジトリ名>/ を開きます。
6. 変更を加えたときは、同じリポジトリのファイルを更新します。数分後にサイトへ反映されます。

【スマホのホーム画面に追加】
iPhone：Safariで公開URLを開く → 共有ボタン →「ホーム画面に追加」→ 追加。
Android：Chromeで公開URLを開く → 右上の︙ →「ホーム画面に追加」または「アプリをインストール」。
端末によって表示名は少し異なります。

【この端末だけで使う場合】
・記録はそのブラウザのローカル保存領域に保存されます。
・写真はブラウザ内のIndexedDBに保存されます。
・別端末とは同期されません。ブラウザのデータ削除や端末故障の前に、設定からバックアップしてください。
・デモPINは初期値1108です。設定から変更できますが、画面を隠すための簡易ロックであり、端末内データを暗号化する仕組みではありません。

【2台で無料同期する：Supabase Free】
必須ではありません。ふたりのスマホでチャット・写真・手紙・予定を同期したい場合だけ設定してください。

1. https://supabase.com/ で無料アカウントを作り、Freeプランで新規プロジェクトを作成します。
2. Supabase Dashboard → SQL Editor → New query を開き、同梱の supabase_setup.sql 全文を貼り付けて実行します。
3. Authentication → Sign In / Providers → Email でメール認証の設定を確認します。個人利用のテストでは、必要に応じてメール確認をオフにすると登録後すぐにログインできます。公開URLを持つアプリなので、招待コードは恋人以外に共有しないでください。
4. Project Settings / API Keys などの画面から Project URL と Publishable key（古い画面では anon public key）を取得します。
5. アプリの「家の設定」→「無料クラウド同期」にURLと公開キーを入力し、「接続設定を保存」を押します。
6. 1台目でメールアドレスと8文字以上のパスワードを入力し「新規アカウント作成」→「ログイン」。
7. 「ふたりの部屋をつなぐ」で呼び名を入力し、新しい部屋を作成します。表示された招待コードを「コードをコピー」でコピーし、恋人に個別のメッセージで渡します。
8. 2台目も同じ公開URLを開き、同じSupabase URL・公開キーで設定します。恋人は別のアカウントを作成してログインし、呼び名と招待コードを入力して参加します。
9. それぞれの端末で合言葉を入力してアプリを開けば、同じ部屋のデータが共有されます。

【絶対に課金しないために】
・SupabaseはFreeプランのまま使い、支払情報の登録や有料プランへのアップグレードはしないでください。
・無料枠には上限があります。プロジェクトのストレージ上限は1GBです。このアプリは写真を縮小してからアップロードしますが、大量の写真を保存する場合は古い写真を整理してください。
・Supabaseの無料プロジェクトは、一定期間使わないと一時停止される場合があります。
・アプリ内に「課金」や自動アップグレードの処理はありません。無料枠を超えて動かなくなった場合は、課金せずに使用量を整理してください。

【データとセキュリティ】
・アプリに入力するのは Supabase の Project URL と公開キーだけです。service_role key、secret key、データベースのパスワードは絶対に入力しないでください。
・クラウドのデータは、SQLで設定したRLS（行レベルセキュリティ）で部屋のメンバーに限定されます。写真バケットは非公開で、閲覧時に期限付きURLを発行します。
・秘密のサプライズは、作成者はすぐに読めますが、受取人は公開日になるまで本文を取得できない構成です。
・このプロトタイプは個人利用向けの試作です。業務情報や極めて機密性の高い情報を保存しないでください。

【動作環境・制約】
・PWAとしてのインストールには、GitHub PagesなどHTTPSのサイトが必要です。
・クラウド同期・リアルタイムチャットにはネット接続が必要です。見た目や端末内データはオフラインでも一部利用できます。
・Supabaseの無料枠の条件は変更される場合があります。利用前に最新のFreeプラン条件を確認してください。
